# Expense Tracker (Трекер расходов)

CLI-приложение на Python для учета личных финансов. 

## Функционал
- Добавление расходов (категория и сумма).
- Просмотр всех записей.
- Расчет общей суммы и среднего чека.
- Защита от ошибок ввода (try/except): программа не падает, если вместо суммы ввести буквы или символы.

## Стек
- Python 3
- Работа со списками и словарями
- Обработка исключений (try/except)
- Функции и циклы (while, for)

## Как запустить
1. Скачайте файл main.py (или expenses.py).
2. Откройте терминал в папке с файлом.
3. Запустите: python main.py
